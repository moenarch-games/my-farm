# Agent Instructions

My Farm is a local farming sim prototype. Domain context: `docs/agents/domain.md`.

Decision Atlas: `docs/decisions/atlas.md` is the one canonical nested-list Markdown source for the owner's product decisions. Add new owner decisions with the next unused dotted sibling ID; never renumber, reorder, remove, reuse or silently replace an earlier decision. Superseding a choice requires a new linked ID. Update linked issues for implementation/acceptance, but do not create a parallel decisions database or mark unverified gameplay as implemented.
